# Overview

The goal of this introductory course is to build an intuition for how a zephyr
application works. We won't explain everything, be you should be left with a
solid foundation for further learning. In the end, you'll have your own Blinky.
If ever in doubt, feel free to reference the [demo implementation](https://github.com/Nuddel69/Zephyr-Course/tree/main/Blinky) in the course
repository.

## Prerequisites

- Some basic knowledge of C

- A development board containing a [zephyr-supported
](https://docs.zephyrproject.org/latest/boards/index.html#) board/SOC (this course
will assume use of the `nucleo_h753zi` by ST-Microelectronics)

- Devicetree compiler (most systems have this preinstalled)
- Git
- Python
- CMake
- Ninja

Additionally, if using an ST SOC:

- [stm32cubeprogrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)

Or (experimental):

- [OpenOCD](https://openocd.org/pages/getting-openocd.html)
