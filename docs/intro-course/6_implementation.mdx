# 6. The Implementation

The *how* of our GPIO application is described by some implementation. Notice
how we've completely disregarded any concern for our GPIO controller; no
mention of it's memory map or even pin multiplexers. The creation of one such
implementation is not within the scope of this course, as it involves a heavy
dose of macro magic and some fancy C. It is, however an interesting topic and
one you undoubtedly will encounter if working with
zephyr. Refer to the [Further Reading](/intro-course/further_reading) section of the overview to find some
resources describing driver implementation.
