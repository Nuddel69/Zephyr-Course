Overview

Prerequisites​

  • Some basic knowledge of C

  • A development board containing a zephyr-supported board/SOC (this course will assume use of the nucleo_h753zi by ST-Microelectronics)

  • Devicetree compiler (most systems have this preinstalled)

  • Git

  • Python

  • CMake

  • Ninja

Additionally, if using an ST SOC:

  • stm32cubeprogrammer

Or (experimental):

  • OpenOCD
